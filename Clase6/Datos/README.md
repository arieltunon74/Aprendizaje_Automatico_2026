# 📊 Datos

Esta carpeta contiene los archivos de datos utilizados en los diferentes proyectos, ejercicios y prácticas de **Aprendizaje Automático**.

## 📁 Contenido

Los archivos pueden encontrarse en diferentes formatos según el proyecto y la herramienta utilizada:

| Formato | Extensión | Descripción                                                             |
| ------- | --------- | ----------------------------------------------------------------------- |
| CSV     | `.csv`    | Datos tabulares separados por comas u otros delimitadores.              |
| JSON    | `.json`   | Datos estructurados en formato JSON.                                    |
| Excel   | `.xlsx`   | Hojas de cálculo utilizadas para análisis y procesamiento de datos.     |
| HTML    | `.html`   | Archivos con tablas o información obtenida desde páginas web.           |
| TXT     | `.txt`    | Archivos de texto plano con información estructurada o sin estructurar. |
| XML     | `.xml`    | Datos estructurados mediante etiquetas XML.                             |
| SQL     | `.sql`    | Scripts o archivos relacionados con bases de datos SQL.                 |

## 🎯 Objetivo

La carpeta `datos` tiene como objetivo centralizar los **datasets y archivos de entrada** utilizados en los proyectos de Aprendizaje Automático.

Estos archivos pueden ser utilizados para:

* Exploración y análisis de datos (EDA).
* Limpieza y transformación de datos.
* Preparación de datos para modelos de Machine Learning.
* Análisis estadístico.
* Entrenamiento y evaluación de modelos.
* Pruebas y ejercicios de programación.
* Visualización de información.

## ⚠️ Consideraciones

* Los archivos originales deben conservarse sin modificaciones cuando sean utilizados como fuente de datos.
* Los archivos procesados o transformados deben identificarse claramente.
* No se deben incluir datos personales, confidenciales o información sensible.
* Para archivos de gran tamaño, se recomienda utilizar un repositorio o sistema de almacenamiento adecuado en lugar de incorporarlos directamente al repositorio de GitHub.
* Se recomienda documentar el origen y la finalidad de cada dataset cuando corresponda.

## 🔄 Flujo de trabajo

Un flujo típico de trabajo puede ser:

```text
Datos originales
       ↓
Limpieza y transformación
       ↓
Datos procesados
       ↓
Análisis exploratorio (EDA)
       ↓
Preparación de variables
       ↓
Entrenamiento del modelo
       ↓
Evaluación
       ↓
Resultados
```
